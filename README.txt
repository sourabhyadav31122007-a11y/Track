NEET Study Tracker (installable app)

Files: index.html, manifest.webmanifest, sw.js, icon-*.png
Upload ALL files to the same folder of any free static host (Netlify Drop, GitHub Pages, Cloudflare Pages).
Open the hosted link in Chrome, then menu > Install app (or Add to Home screen).

Moving your data: in the old tracker open Backup & restore > Copy backup,
then in the new app open Backup & restore, paste into the box and tap Restore from text twice.
